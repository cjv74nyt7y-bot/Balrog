# Flee the Balrog

A touch-friendly arcade game for iPad (also works on phones and desktop browsers).
Climb the shaft out of the deep while dodging embers, boulders and the fire whip.

## Play

Open `index.html` in Safari on your iPad. For full-screen play, tap **Share → Add to Home Screen**.
To host it, enable GitHub Pages for this repository (Settings → Pages → deploy from branch).

## Controls

- **Drag anywhere** to move the wizard.
- **Tap ✦** (or touch with a second finger) to cast a ward that clears nearby hazards.
- Desktop: arrow keys / WASD to move, Space to ward, P to pause.
